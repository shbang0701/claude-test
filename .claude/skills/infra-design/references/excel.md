# Excel 도면 디자인 기준

코드: `_build/xlkit.py` (격자 `Canvas`, 셀 스타일) · `_build/xlparts.py` (부품) · `_build/xldevices.py` (장비) · `_build/xlforms.py` (빈 양식) · `_build/xlexamples.py` (예시) · `_build/xlguide.py` (사용법·기준 시트) · `_build/xlrack.py` (랙 시트)

## 핵심: 셀 격자 도면, 도형 없음

- 모든 시트가 같은 격자를 쓴다: 열 너비 2.0 · 행 높이 12pt ≈ 4.2mm 정사각형. 시트는 `Canvas(wb, 이름, tab=탭색)`로만 만든다.
- 도면은 셀 채움 + 테두리 + 병합으로만 그린다. 그림, 도형, 텍스트 상자는 쓰지 않는다 (행 삽입, 시트 복사, 인쇄에서 어긋나기 때문).
- 병합은 `cv.merge()`로 모아 두고 `cv.finalize()`에서 한꺼번에 처리한다. 병합이 겹치면 안 된다.

## 크기

| 항목 | 기준 |
|---|---|
| 장비 폭 | 19인치 = 61칸 (C~BK열, 양 끝 1칸은 랙 귀) · 반폭 30칸 · 타워 29칸 · 소형 = 실제 폭 mm ÷ 8칸 |
| 장비 높이 | 1U 5칸 · 2U 10칸 · 3U 이상 U당 4칸 · 한 면 최대 38칸 (= 한 쪽) |
| 모듈 | 높이 2칸 (제목+포트 / 포트명) · 1칸 (띠형) · 3칸 · 폭 1/3 = 19칸, 1/2 = 29칸, 전체 = 59칸 |
| 간격 | 모듈 사이 1칸 · 외곽선 안쪽 위아래 1칸 · 위아래로 쌓는 슬롯 0칸 |
| 포트 | 2칸 (RJ45 · SFP · LC · USB · C14) · 3칸 (QSFP · SAS HD · D-sub · C20 · CXP) · 포트 사이 1칸, 고밀도 0칸 |
| 디스크 | SFF 2×6칸 = 디스크 5 + 베이 번호 1 (1U는 2×3) · LFF 14×2칸 = 번호 2 + 디스크 |

## 글자 (맑은 고딕, 케이블 라벨만 Consolas)

장비명 16pt 굵게 · 모델 11pt `s700` · 구역 탭 8pt 굵게 흰색 (남색 바탕) · 모듈 제목 7pt 굵게 · 도면 번호 8pt 굵게 흰색 · 포트명 6.5pt `s500` · 디스크 6pt · 표 본문 8.5pt · 케이블 라벨 8.5pt Consolas (노란 칸) · 메모 7pt `s500`

## 선

| 대상 | 선 |
|---|---|
| 장비 외곽 | `medium` `s700` |
| 모듈 | `thin` `s400` |
| 빈 슬롯 | `dashed` `s300` |
| 포트·디스크 구분 | `medium` `s150` (모듈 바탕색과 같아 틈처럼 보임) |
| RAID 묶음 | `thick` `ink` 바깥쪽 테두리 |
| 표 줄 | `thin` `s200`, 머리글 위아래 `thin` `s400` + `s100` 바탕 |

## 셀 스타일 (홈 > 셀 스타일에 노출됨)

`포트 서비스` ~ `포트 전원` · `포트 미연결` · `포트명` · `모듈 제목` · `모듈 채움` · `디스크 장착` · `디스크 빈칸` · `RAID 표시` · `번호 배지` · `케이블 라벨` · `구역 제목` · `메모` · `표 머리글` · `표 본문` · `표 번호`

- 사용자가 직접 색을 칠하지 않고 셀 스타일을 고르도록 만든다. 새 스타일은 `_defs()`에 추가한다.
- 포트·디스크 스타일에는 테두리를 넣지 않는다 (`NO_BORDER_STYLES`). 적용해도 도면 테두리가 유지되어야 한다. `RAID 표시`는 바탕색도 유지한다 (`NO_FILL_STYLES`).

## 번호 3종 분리

- **도면 번호**: 용도 색 칸 안의 흰 숫자. 장비 안에서 유일하다. 스위치·패치패널·PDU는 인쇄된 포트 번호를 그대로 쓰고, 모듈·노드·블레이드는 슬롯×100+포트.
- **포트명**: 포트 아래 회색 6.5pt (`LOM1`, `P1`).
- **케이블 라벨**: 표의 노란 칸에만 Consolas로 (`R02-D001`).
- 표의 번호 칸은 조건부 서식으로 도면에 없거나 중복된 번호를 분홍(`warn_bg`/`warn_fg`)으로 표시한다. 새 양식에도 이 검사를 유지한다.

## 면 · 쪽 구성 · 인쇄

- 면은 랙 기준: 랙 앞문 쪽이 전면 (제조사 표기와 달라도).
- 1~2U: 전면 + 후면 + 표(약 14줄) 한 쪽 · 3~4U: 전면 + 후면 한 쪽, 표는 다음 쪽 · 5U 이상: 면마다 한 쪽 · 스위치류: 2단 표.
- A4 가로 · 배율 100% (너비가 넘칠 때만 1쪽 너비 맞춤) · 여백 좌우 10mm, 위아래 12mm · 1~3행 반복 · 바닥글 = 파일명 · 시트명 · 쪽 번호. `cv.page_setup()`을 쓴다.
- 여러 박스로 된 시스템(본체 + I/O 드로어 등)은 박스마다 시트를 두고, 제목 옆 역할 배지로 구분한다.

## 시트 이름과 탭 색

`양식-…` 파랑 (빈 양식) · `예시-…` 초록 (작성 예시) · 부품 주황 (`D9822B`) · 안내 회색. 랙 파일의 장비 시트는 `U20 SRV-01`처럼 U 위치 + 장비명.
