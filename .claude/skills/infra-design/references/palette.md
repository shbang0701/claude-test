# 팔레트

원본: `_build/xlkit.py`와 `_build/ppt_kit.py`의 `P`. 코드에서는 항상 키로 참조한다.

## 기본 (글자 · 선 · 바탕)

| 키 | hex | 쓰임 |
|---|---|---|
| `ink` | `#1E2A36` | 기본 글자, 제목 |
| `navy` | `#1F3A5F` | 강조, 번호 배지, 구역 탭, 아이콘 기본색 |
| `s700` | `#3A4856` | 진회색: 장비 외곽선, 보조 제목 |
| `s600` | `#4E5D6C` | 데이터센터 영역 테두리 |
| `s500` | `#677789` | 보조 글자, 바닥글, 포트명, hex 표기 |
| `s400` | `#8C99A8` | 모듈 선, 비활성 글자 |
| `s300` | `#B4BFCB` | PPT 테두리, 빈 슬롯 점선 |
| `s200` | `#D5DCE4` | 표 줄 |
| `s150` | `#E4E9EF` | 모듈 바탕, 포트 구분선 |
| `s100` | `#EEF2F6` | 표 머리글 바탕 |
| `s50` | `#F6F8FA` | 연한 바탕 |
| `white` | `#FFFFFF` | |

## 용도 (연결 종류) — Excel·PPT 공통

| 키 | hex | 이름 | 뜻 |
|---|---|---|---|
| `svc` | `#2F6DB5` | 서비스 | 업무·데이터 이더넷 |
| `mgmt` | `#0B7C7C` | 관리 | OOB · BMC · iLO · iDRAC |
| `bak` | `#377F3F` | 백업 | 백업 전용망 |
| `san` | `#BF5B14` | 스토리지 | SAN · FC · SAS · iSCSI |
| `ic` | `#7A55B3` | 인터커넥트 | HA · 스택 · 피어링크 · IB · DR 복제 |
| `con` | `#5E6B78` | 콘솔 | 시리얼 콘솔 |
| `pwr` | `#C73E3A` | 전원 | PSU · PDU · UPS |
| `wan` | `#3A4856` | WAN (PPT만) | 대외 · 전용회선 |

용도 색 위의 글자는 흰색 굵게 쓴다.

## 영역 바탕 (PPT 영역 박스 · 카드, 옅은 색)

`t_svc #EAF1FA` · `t_mgmt #E5F2F2` · `t_bak #EAF3EB` · `t_san #FBEFE6` · `t_ic #F1ECF8` · `t_pwr #FAEAE9` · `t_ext #F1F3F5`
(DMZ만 예외: 바탕 `#FDF6E7`, 테두리 `#C98A1A` — `ZONES`에 정의됨)

## 상태 (PPT)

| 상태 | 글자/선 | 바탕 |
|---|---|---|
| 정상 `ok` | `#2E8B57` | `t_ok #E6F3EC` |
| 주의 `warn` | `#D98E04` | `t_warn #FDF3DE` |
| 장애 `crit` | `#C73E3A` | `t_crit #FAE7E6` |
| 정보 `info` | `#2F6DB5` | `t_info #E8F0FA` |

상태 태그는 옅은 바탕 + 진한 글자. 꽉 찬 색 태그(`solid=True`)는 강조할 때만 쓴다.

## Excel 전용

`tape #FFF1BF` 케이블 라벨 노란 칸 · `disk #C3CCD6` 장착 디스크 · `warn_bg #F8D3D0` / `warn_fg #9B1C17` 번호 누락·중복 분홍 경고

## 탭 색 (Excel 시트)

회색 = 안내 · 주황 = 부품 · 파랑 = 빈 양식(`양식-`) · 초록 = 작성 예시(`예시-`)
