# PPT 디자인 기준

코드: `_build/ppt_kit.py` (기본 헬퍼) · `_build/ppt_elements.py` (요소) · `_build/ppt_slides_a/b/c.py` (슬라이드) · `_build/build_ppt.py` (순서·목차)

## 슬라이드 틀

- 16:9, 13.333 × 7.5in. `new_presentation()`이 테마 색, 맑은 고딕, 그림자 제거, 바닥글을 맞춰 준다. 직접 `Presentation()`을 만들지 않는다.
- 새 슬라이드는 `slide(prs, title, eyebrow)`로 만든다.
  - 분류(eyebrow): (0.5, 0.2)in, 9pt 굵게, `svc` 파랑
  - 제목: (0.5, 0.42)in, 폭 12.33in, 24pt 굵게, 왼쪽 정렬, 아래 맞춤
  - 바닥글 8pt `s500` 왼쪽 + 쪽 번호 오른쪽 (y 7.08in, 레이아웃에 들어 있음)
- 본문 영역은 y ≈ 1.3in부터 시작, 좌우 여백 0.5in (오른쪽 끝 x = 12.83in), 바닥글 위 7.0in 안쪽에서 끝낸다.
- 요소 사이 간격 0.3in. 열을 나눌 때 x 좌표를 맞춰 정렬선을 만든다.
- 발표자 노트에 사용법을 적을 때는 `notes(sl, "...")`.

## 글자

| 용도 | 크기 |
|---|---|
| 슬라이드 제목 | 24pt 굵게 |
| 소제목 | 14pt 굵게 (구역 제목은 12pt 굵게도 사용) |
| 본문 | 11–12pt |
| 장비 이름 | 10.5pt 굵게 |
| 설명 · 표 | 9–9.5pt |
| 각주 · 출처 · hex | 8pt (hex 7pt) `s500` |

`text()`가 맑은 고딕과 `lang=ko-KR`을 넣어 준다. python-pptx의 run에 직접 글꼴을 넣을 때는 `set_font()`를 쓴다.

## 연결선 (`LINES` — 색 + 굵기 + 선 모양으로 구분)

| 키 | 이름 | 색 | 굵기 | 모양 |
|---|---|---|---|---|
| `svc` | 서비스 | `svc` | 1.75 | 실선 |
| `san` | 스토리지 (SAN) | `san` | 1.75 | 실선 |
| `mgmt` | 관리 (OOB) | `mgmt` | 1.25 | 짧은 점선 `sysDash` |
| `bak` | 백업 | `bak` | 1.25 | 긴 쇄선 `lgDashDot` |
| `ha` | HA · 스택 · 피어링크 | `ic` | 1.25 | 점 `sysDot` |
| `dr` | 복제 · DR | `ic` | 1.75 | 긴 점선 `lgDash` |
| `wan` | WAN · 인터넷 | `wan` | 2.25 | 실선 |
| `pwr` | 전원 | `pwr` | 1.25 | 실선 |

- 흑백 인쇄에서도 구분되도록 색만이 아니라 선 모양도 다르게 둔다.
- 연결선은 `connect()`로 도형 연결점에 붙인다 (도형을 옮기면 따라온다). 직선 `line()`은 장식용으로만 쓴다.
- 연결선이 있는 슬라이드에는 `line_legend()` 범례를 둔다.

## 영역 박스 (`ZONES`)

`ext` 인터넷·외부 · `dmz` · `svc` 내부 서비스망 · `mgmt` 관리망 · `bak` 백업망 · `san` 스토리지망 · `dr` DR 센터 · `cloud` 클라우드(VPC) · `phys` 데이터센터 · `group` 클러스터(바탕 없음, 점선) · `sec` 보안 경계(빨간 파선). 새 영역 종류가 필요하면 `ZONES`에 추가하고 기존 색을 재사용한다.

## 요소 만들기 규칙

- **요소 하나 = 이름 붙은 그룹 하나.** `group(sl, shapes, "이름")` 또는 각 헬퍼의 `gname=`. 사용자는 한 번 클릭으로 선택·복사하고, 선택 창(Alt+F10)에서 이름으로 찾는다. 이름은 한글로 뜻을 적는다 (`범례-연결선`, `카드-DB-01`).
- 기존 요소 헬퍼를 먼저 쓴다: `node_card` · `node_compact` · `node_tile` · `node_box` (장비), `zone`, `pill` · `badge` · `tag` (라벨), `line_legend` · `color_legend`, `kpi` · `usage_bar` (현황), `steps` (절차), `checkbox`, `rack`, `table`.
- 장비 카드 = 아이콘 + 이름(10.5 굵게) + 보조 정보(IP·모델, 8–9pt `s500`).
- 표는 `table()`로 만든다: 기본 머리글 = 남색 바탕 + 흰 글자, 9.5pt. 차분한 표는 `head_fill=P["s100"]`(잉크 글자로 바뀜).

## 슬라이드 추가 순서

1. 요소 슬라이드는 `ppt_slides_b.py`, 완성 샘플은 `ppt_slides_c.py`(`SAMPLES` 목록에 등록)에 함수로 추가한다.
2. `build_ppt.py`의 `plan`(목차)과 호출 순서에 넣는다. 목차 쪽 번호는 `plan`에서 계산된다.
3. 다시 만들고 PDF → PNG로 렌더링해 확인한다.
