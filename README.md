# 문서 작성 · 시각화 라이브러리

Office 2016에서 **복사해 붙여 쓰는 도구 모음**이다.
주제나 분야를 가리지 않는다. 발표 · 설명 · 교육 · 안내 · 제안 · 보고 어디에나 쓴다.

디자인을 고민하는 시간을 줄이고 내용에만 집중하도록, 실제로 쓰는 도형 · 표 · 서식을
완성된 상태로 넣어 두었다. LLM이나 별도 프로그램 없이 Office 기본 기능만으로 쓴다.

## 5분 시작

0. `library/00_시작가이드.docx` 를 연다. 2장의 **찾아보기 표**에서 전하려는 내용을 찾으면
   Word 블록 번호 · PPT 쪽 번호 · Excel 시트가 한 줄로 나온다.
1. `preview/` 의 미리보기 이미지를 열어 그 번호를 눈으로 확인한다.
2. 해당 파일을 열고 그 부분을 선택해 복사한다.
3. 작업 중인 문서에 붙여 넣는다. **다른 양식의 문서라면 붙여넣기 옵션에서 ‘원본 서식 유지’**.
4. `〈 〉` 안의 글자를 실제 내용으로 바꾼다.
5. 회색 안내 글(작성 안내 · 쓰는 법)은 지운다.

## 무엇이 어디 있나

**Word** — 읽고 따라 하는 문서
문서의 시작(요약 · 범위) · 설명(정의 · Q&A · 인용) · 순서(단계 3밀도 · 분기 · 확인)
· 입력과 결과 · 비교 · 수치 · 그림 · 마무리 · 문단과 글자 다루기

**PowerPoint** — 핵심과 관계를 보여주는 문서
표지 · 목차 · 핵심과 근거 · 요약 카드 · 구성 · 계층과 관계 · 단계 · 일정 · 전후 · 선택지
· 두 축 비교 · 지표 · 막대 · 추세와 구성비 · 화면 주석 · 여러 장 · 표 · 마무리
**도구상자**: 선과 화살표 · 상자와 테두리 · 말풍선과 괄호 · 순서 부품 · 강조 부품
· 그림 부품 · 정렬 요령 · 색과 글자 요령 · 단축키
**부록**: 디자인 기준(색 12 · 글자 · 선 · 간격) · 아이콘 60종(진한 색 / 흰색)
**IT 인프라**: 장비 요소 · 랙 · 영역 박스 · VLAN 라벨 · 작업 절차(수행용) ·
완성 예 6장(시스템 구성도 · 랙 실장도 · 서버 결선도 · 작업 계획 · 장애 보고 · 점검 결과)

**Excel** — 정돈하고 비교하고 확인하는 문서
셀로 만드는 시각 요소(카드 · 배지 · 구분선 · 진행 막대 · 아이콘 · 셀 도식)
· 표 서식 4종 · 한 장 요약 · 일정표(간트) · 자주 쓰는 함수 18개 · 미리 켜 둔 리본 기능 12가지

## 두 종류의 문서

- **00~04** — 복사해 쓰는 라이브러리. 만들어진 것을 가져다 쓴다.
- **05~07** — Office 기능 자체를 익히는 실무 가이드. 빈 파일에서 시작하거나,
  머리글·표·수식처럼 직접 다뤄야 할 때 본다. 각 항목에 [기본] / [심화] 가 붙어 있다.

python3 tools/build_guide.py && python3 tools/build_word_guide.py && \
