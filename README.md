# IT 인프라 문서 작성 라이브러리

Office 2016에서 바로 쓰는 운영 문서용 서식 모음이다.
필요한 부분을 찾아 복사하고, 실제 업무 내용만 채워 넣으면 문서가 완성되도록 만들었다.
LLM이나 별도 프로그램 없이 Word·PowerPoint·Excel의 기본 기능만으로 쓴다.

## 파일

| 파일 | 무엇 | 언제 |
|---|---|---|
| `library/01_운영매뉴얼_템플릿.docx` | 표지·목차·본문 구조가 갖춰진 운영 매뉴얼 뼈대 | 고객용 운영 매뉴얼을 새로 쓸 때 |
| `library/02_Word_블록라이브러리.docx` | 단계·명령·출력·주의·화면·표 등 22종 블록 | 문서에 필요한 조각을 가져다 쓸 때 |
| `library/03_인프라_시각요소.pptx` | 구성도·흐름·비교·상태·화면주석 15장 | 구성도, 작업 계획/결과, 장애 보고를 그릴 때 |
| `library/04_운영문서_표모음.xlsx` | 작업계획·점검·관리대장·장애기록·비교·인수인계 7시트 | 기록하고 넘겨주는 표가 필요할 때 |

## 5분 시작

1. `01_운영매뉴얼_템플릿.docx`를 열어 다른 이름으로 저장한다.
2. 표지와 문서 정보의 `〈 〉` 부분을 실제 값으로 바꾼다.
3. 3장(일상 운영)의 예시 절차를 지우고, `02_Word_블록라이브러리.docx`에서
   필요한 단계 블록을 복사해 붙여 넣는다.
4. 구성도가 필요하면 `03_인프라_시각요소.pptx` 3쪽을 고쳐서 복사해 넣는다.
5. 회색 안내 문단(IT-작성안내)을 모두 지우고, 목차 위에서 F9로 목차를 갱신한다.

## 읽을 것

- `guide/01_Word_작성법.md` — 스타일과 블록, 무엇을 적고 무엇을 생략할지
- `guide/02_PPT_Excel.md` — 시각 요소와 표 시트 사용법
- `guide/03_수정_복사_인쇄.md` — 서식 충돌, 이미지 교체, 인쇄·PDF, 검증 범위

## 설계 원칙

- **그림이 아니라 편집 가능한 요소.** 모든 내용은 텍스트·표·도형이다. 값만 바꾸면 된다.
- **스타일로 관리.** Word의 서식은 `IT-`로 시작하는 스타일에 모여 있다.
  스타일 하나를 고치면 문서 전체가 같이 바뀐다.
- **자동으로 따라오는 번호.** 제목(1, 1.1)과 단계 번호는 자동이다.
  중간에 단계를 끼워 넣어도 뒤 번호가 알아서 밀린다. 제목이 바뀌면 단계는 1부터 다시 시작한다.
- **필요한 만큼만.** 간단한 작업은 지시문과 명령 한 줄로, 위험한 작업은 사전조건·주의·판정까지.
  모든 단계에 같은 항목을 기계적으로 반복하지 않는다.

## 다시 만들기 (선택)

결과물은 `library/`에 이미 들어 있다. 디자인이나 내용을 바꿔 다시 만들려면:

```bash
pip install python-docx python-pptx openpyxl pillow
python3 tools/build_assets.py   # 자리표시 이미지
python3 tools/build_docx.py     # Word 2종
python3 tools/build_pptx.py     # PowerPoint
python3 tools/build_xlsx.py     # Excel
python3 tools/selftest.py       # 편집·복사·인쇄 시뮬레이션(LibreOffice 필요)
```

색·글꼴은 `tools/design.py` 한 곳에서 관리한다.
