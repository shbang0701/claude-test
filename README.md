## 바로 시작

**Excel — 새 장비 도면**
1. 가장 비슷한 `예시-`/`양식-` 시트 탭 우클릭 → **이동/복사** → 대상 = 랙 파일 → **복사본 만들기**
2. 시트 이름을 `U20 SRV-01`처럼 (U 위치 + 장비명)
3. 1~2행 머리글 입력
4. [부품] 시트에서 부품 범위 복사 → 놓을 자리의 **왼쪽 위 칸** 클릭 → 붙여넣기 (같은 크기면 그대로 교체됨)
5. 연결된 포트 칸에 도면 번호 입력 → [홈 > 셀 스타일] `포트 서비스` 등으로 색 지정
6. 디스크: 칸 안에 용량(`1.92T SSD`) 입력 → 그 칸 복사 → 다른 디스크 칸들을 한꺼번에 선택해 붙여넣기. 빈 베이는 `빈`. RAID는 묶을 디스크 범위에 **굵은 바깥쪽 테두리** + 아래 줄에 `RAID5 · DATA`
7. 아래 표 작성 → 번호 칸이 **분홍색**이면 도면에 그 번호가 없거나 두 번 이상 있음

**랙 파일에 등록**: [랙] 시트 목록 빈 줄에 U · 높이 · 면 · 장비명 · (시스템) · 모델 · 구분 · 시트 이름 → 실장도가 자동으로 그려지고 ▶ 링크가 생깁니다.
- 한 시스템인 박스(본체 + I/O 드로어, 컨트롤러 + 디스크 선반)는 **시스템** 칸에 같은 이름
- 선반·트레이는 구분 `선반`으로 한 줄, 그 위 장비는 면 `선반` (실장도·U 겹침에서 빠지고 링크는 유지)

**인쇄**: 모든 시트가 A4 가로 · 100% · 바닥글(파일명·시트명·쪽 번호)로 설정되어 있습니다. 배율은 줄이지 마세요.

**PPT**: 요소를 한 번 클릭(그룹 선택) → Ctrl+C → 대상 PPT에 Ctrl+V. 색은 RGB, 글꼴은 맑은 고딕으로 직접 지정되어 있어 다른 회사 양식에 붙여도 모양이 그대로입니다. Office 2016은 SVG 삽입이 안 되므로 아이콘은 PPT 아이콘 슬라이드의 도형을 복사하거나 PNG를 쓰세요.

## 설계 판단

- **Excel 도면 = 셀 격자(1칸 ≈ 4.2mm), 도형 없음.** 모든 시트가 같은 격자라 부품을 어디에 붙여도 크기·정렬이 같고, 행 삽입·시트 복사·인쇄에서 어긋나지 않습니다.
- **전면·후면·표는 한 시트에.** 도면 번호는 장비 안에서 유일해야 하고, 분홍 경고(번호 누락·중복)가 앞뒤를 함께 검사합니다. 큰 장비는 쪽 나누기로 면마다 한 쪽.
- **면 = 랙 기준.** 랙 앞문 쪽에서 보이는 면이 전면(제조사 표기와 달라도). 앞에 관리 포트가 있는 장비, 뒤에 디스크를 꽂는 장비도 부품을 해당 면에 붙이면 됩니다.
- **번호 3종 분리**: 도면 번호(색 칸 흰 숫자) · 포트명(포트 아래 회색 글씨) · 케이블 라벨(표의 노란 칸에만). 스위치·패치패널·PDU는 인쇄된 포트 번호 = 도면 번호, 모듈·노드·블레이드 섀시는 슬롯×100+포트.
- **디스크는 칸 안에 용량, RAID는 테두리.** 디스크 한 개씩 표로 만들지 않고, 용량 글씨를 복사해 붙이고 묶음은 굵은 바깥쪽 테두리로 표시합니다. 빈 베이·빈 슬롯도 '빈'으로 남깁니다.
- **여러 박스 = 박스마다 시트 + 시스템 이름 + 역할 배지.** 겉모양이 같은 IBM Power 본체와 I/O 드로어도 제목 옆 배지(본체 / I/O 드로어)와 후면 도면(HMC 포트 유무, T1·T2 광케이블 포트)으로 구분됩니다.
- **랙 1대 = 파일 1개**: 장비 200대 → 랙 파일 10~20개. [랙] 시트는 목록 입력만으로 실장도·U 겹침 경고·사용 U 합계·시트 링크가 수식으로 갱신됩니다(매크로 없음).
- **PPT 요소 = 이름 붙은 그룹**, 연결선은 도형 연결점에 붙어 있어 도형을 옮기면 따라옵니다.

- **작업 흐름 자동 검수 18단계 중 17 통과** (LibreOffice를 UNO로 실제 조작): 양식 선택 → 다른 파일로 시트 복사 → 부품 붙여넣기(병합 유지) → 번호 입력·셀 스타일 적용(테두리 유지) → **디스크 용량 한 칸 입력 후 여러 베이에 한 번에 붙여넣기**(병합·베이 번호 유지) → 표 입력·줄 추가 → 랙 목록 등록(실장도·링크·합계 갱신, U 겹침 경고) → **선반 + 선반 위 장비**(겹침 경고 없음, 장비 수에서 선반 제외) → PDF 인쇄 → 예시 랙에 같은 모델 추가. 오타 번호(99)는 분홍색으로 표시됨
  - 실패 1건: LibreOffice의 시트 가져오기는 **인쇄 설정을 기본값으로 바꿈**. Excel의 [이동/복사]는 시트별 인쇄 설정을 함께 복사하지만, Excel에서 직접 확인하지는 못했습니다
  - LibreOffice는 내용이 있는 칸에 붙여넣을 때 '덮어쓸까요?'를 묻습니다(검수에서는 [예]로 처리). Excel은 묻지 않고 덮어씁니다

## 다시 만들기 (선택)

`_build/`의 Python 스크립트로 모든 파일을 다시 만들 수 있습니다. 필요: Python 3 + openpyxl · python-pptx · lxml · cairosvg · pypdf, LibreOffice(`soffice`가 PATH에 있어야 함).

```bash
cd _build
python3 build_excel.py
python3 inject_cache.py ../01_엑셀_장비도면/2_랙예시_DC1-R02.xlsx ../01_엑셀_장비도면/3_랙_빈양식.xlsx   # 수식 계산 값 미리 넣기
python3 build_icons.py
python3 build_ppt.py
python3 build_docs.py
/usr/bin/python3 qa_workflow.py <출력폴더>   # 작업 흐름 검수 (python3-uno 필요)
```

소켓 사용이 막힌 환경에서는 `LO_HELPER` 환경 변수로 LibreOffice 실행 도우미를 지정합니다(`lo.py` 참고).
