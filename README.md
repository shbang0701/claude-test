# IT 인프라 문서 템플릿 · 에셋 세트

장비 전면·후면도(Excel)와 구성도·보고서용 PPT 요소, IT 인프라 아이콘 60종을 한 세트로 묶었습니다.
회사에 반입한 뒤 **Excel·PowerPoint 기본 조작만으로** 계속 쓸 수 있습니다. Visio, 매크로, 코드 실행, 외부 서비스는 필요 없습니다.

## 바로 시작

**Excel — 새 장비 도면 (6단계)**
1. 가장 비슷한 `예시-`/`양식-` 시트 탭 우클릭 → **이동/복사** → 대상 = 랙 파일 → **복사본 만들기**
2. 시트 이름을 `U20 SRV-01`처럼 (U 위치 + 장비명)
3. 1~2행 머리글 입력
4. [부품] 시트에서 부품 범위 복사 → 놓을 자리의 **왼쪽 위 칸** 클릭 → 붙여넣기 (같은 크기면 그대로 교체됨)
5. 연결된 포트 칸에 도면 번호 입력 → [홈 > 셀 스타일] `포트 서비스` 등으로 색 지정
6. 아래 표 작성 → 번호 칸이 **분홍색**이면 도면에 그 번호가 없거나 두 번 이상 있음

**랙 파일에 등록**: [랙] 시트 목록 빈 줄에 U · 높이 · 면 · 장비명 · 모델 · 구분 · 시트 이름 → 실장도가 자동으로 그려지고 ▶ 링크가 생깁니다.
**인쇄**: 모든 시트가 A4 가로 · 100% · 바닥글(파일명·시트명·쪽 번호)로 설정되어 있습니다. 배율은 줄이지 마세요.

**PPT**: 요소를 한 번 클릭(그룹 선택) → Ctrl+C → 대상 PPT에 Ctrl+V. 색은 RGB, 글꼴은 맑은 고딕으로 직접 지정되어 있어 다른 회사 양식에 붙여도 모양이 그대로입니다. Office 2016은 SVG 삽입이 안 되므로 아이콘은 PPT 아이콘 슬라이드의 도형을 복사하거나 PNG를 쓰세요.

## 첨부 자료 검토 → 재사용한 것 · 바꾼 것

| 첨부 | 재사용 | 개선 |
|---|---|---|
| Excel 후면 연결도 (DL380, c7000) | 도면 번호 ↔ 연결 표 대응, 용도별 색, 미연결 = 흰 칸, 빈 슬롯 = 점선, A4 가로 | 제목까지 **절대 위치 도형**이라 셀 복사·행 삽입·인쇄 시 어긋남 → **셀 격자 도면**으로 전환. 장비마다 1쪽 맞춤이라 글자 크기가 제각각 → **고정 축척 100%**. 쪽 번호가 고정 글자 → 자동 바닥글. 번호·라벨 표기 혼재(01 / E01 / F11) → **3종 분리 규칙**. 전면도·랙 단위 관리 없음 → 추가 |
| PPT 후면도 부품·장비 슬라이드 | 부품을 모아 두고 복사하는 방식 | 장비 도면은 Excel로 일원화(PPT에는 '그림으로 복사'로 붙임), PPT에는 구성도·보고서 요소를 제공 |
| PPT 아이콘 18종 · 연결선 규칙 | 선 색 = 통신 종류, 아이콘 + 이름 + IP 카드, 영역 박스 | 비표준 크기(14.22×8in) → **16:9 표준**. Office 2016에 없는 Aptos 글꼴 → 맑은 고딕. 테마 색 의존 → RGB 고정. 18종 → **60종 + SVG/PNG**. 선 규칙 4종 → 8종(Excel 포트 색과 통일) |

## 설계 판단

- **Excel 도면 = 셀 격자(1칸 ≈ 4.2mm), 도형 없음.** 모든 시트가 같은 격자라 부품을 어디에 붙여도 크기·정렬이 같고, 행 삽입·시트 복사·인쇄에서 어긋나지 않습니다. 포트 색은 셀 스타일 한 번 클릭, 연속 번호는 채우기 핸들, 장비명은 Ctrl+H로 일괄 변경.
- **번호 3종 분리**: 도면 번호(색 칸 흰 숫자, 장비 안에서 유일) · 포트명(포트 아래 회색 글씨 = 장비 표기) · 케이블 라벨(표의 노란 칸에만). 스위치·패치패널·PDU는 인쇄된 포트 번호 = 도면 번호, 라인카드 섀시는 슬롯×100+포트.
- **랙 1대 = 파일 1개**: 장비 200대 → 랙 파일 10~20개. [랙] 시트는 목록 입력만으로 전면/후면 실장도·U 겹침 경고·사용 U 합계·시트 링크가 수식으로 갱신됩니다(매크로 없음).
- **PPT 요소 = 이름 붙은 그룹**, 연결선은 도형 연결점에 붙어 있어 도형을 옮기면 따라옵니다.

## 검수 결과

**확인한 것** (이 환경: LibreOffice 24.2 + 스크립트)
- Excel 3개 파일 전 시트 PDF 렌더링 확인, 수식 685개 오류 0, 병합 겹침 0, 랙 실장도 수식 값(위치·이름·합계·링크) 검증
- **작업 흐름 자동 검수 16단계 중 15 통과** (LibreOffice를 UNO로 실제 조작): 양식 선택 → 다른 파일로 시트 복사 → 부품 붙여넣기(병합 유지) → 번호 입력·셀 스타일 적용(테두리 유지) → 표 입력·줄 추가(병합 유지) → 랙 목록 등록(실장도·링크·합계 갱신, U 겹침 경고) → PDF 인쇄 → 예시 랙에 같은 모델 추가. 오타 번호(99)는 분홍색으로 표시됨
  - 실패 1건: LibreOffice의 시트 가져오기는 **인쇄 설정을 기본값으로 바꿈**. Excel의 [이동/복사]는 시트별 인쇄 설정을 함께 복사하지만, Excel에서 직접 확인하지는 못했습니다
- PPT 스키마 검증 통과, 27장 렌더링 확인, 테마 색 참조 0 · 글꼴은 맑은 고딕만 사용. Office 기본 테마(4:3, Calibri) 파일에 요소를 붙여도 색·글꼴 유지 확인
- 아이콘 60종: even-odd / nonzero 두 채우기 규칙에서 픽셀 단위로 같게 그려짐 → PowerPoint 도형에서도 구멍이 맞게 보임

**확인하지 못한 것** (Excel·PowerPoint 2016이 이 환경에 없음)
- Excel 2016 실제 화면·인쇄: 맑은 고딕 글자 폭(검수는 대체 글꼴), 열 너비 반올림, 프린터별 배율(넘치면 1쪽 너비 맞춤이 자동 보정), 셀 스타일 갤러리 표시와 '테두리 유지' 동작, 조건부 서식 테두리, 보호된 보기(계산 값은 미리 넣어 둠)
- PowerPoint 2016: 도형 이동 시 연결선 재배치, 붙여넣기 옵션별 결과, 차트 데이터 편집
- SVG 삽입은 Microsoft 365(구독형)에서만 됩니다. Office 2016 영구 라이선스는 도형 아이콘 또는 PNG를 쓰세요

## 다시 만들기 (선택)

`_build/`의 Python 스크립트로 모든 파일을 다시 만들 수 있습니다. 필요: Python 3 + openpyxl · python-pptx · lxml · cairosvg · pypdf, LibreOffice(`soffice`가 PATH에 있어야 함).

```bash
cd _build
python3 build_excel.py
python3 inject_cache.py ../01_엑셀_장비도면/2_랙예시_DC1-R02.xlsx ../01_엑셀_장비도면/3_랙_빈양식.xlsx   # 수식 계산 값 미리 넣기
python3 build_icons.py
python3 build_ppt.py
python3 build_docs.py
/usr/bin/python3 qa_workflow.py <출력폴더>   # 작업 흐름 검수 (python3-uno 필요)
```

소켓 사용이 막힌 환경에서는 `LO_HELPER` 환경 변수로 LibreOffice 실행 도우미를 지정합니다(`lo.py` 참고).
