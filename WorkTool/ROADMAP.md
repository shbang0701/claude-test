# 요구사항과 진행 순서

## 완료

- 뼈대: 메인 창, 탭, 모듈 로딩
- Storage: CSV 저장 (임시 파일 교체, .bak)
- 메모 탭: 검색·목록·편집, 자동 저장, 빈 제목은 저장 시각

## 진행 순서

1. 일정·근태·알람
2. 서버/랙 현황
3. 파일 서버 작업 기록·증적·메일 본문
4. 문서 탭, 마크다운 미리보기 (아래 요구사항)

순서는 언제든 바꿀 수 있다. 탭 하나가 모듈 하나라서 서로 영향이 적다.

## 요구사항 (대기)

### 마크다운 미리보기

- 메모 본문을 편집 / 미리보기로 전환해서 볼 수 있게 한다.
- 구현 방향: PowerShell 7 내장 `ConvertFrom-Markdown`으로 HTML을 만들고 WinForms `WebBrowser` 컨트롤로 보여준다. 외부 반입 없음.
- 미리보기는 공통 모듈로 만들어 메모 탭과 문서 탭이 같이 쓴다.

### 문서 탭 (폴더 트리)

- 지정한 폴더를 왼쪽 트리(TreeView)로 보여주고, 오른쪽에 파일 목록.
- Excel / Word / PowerPoint 등은 더블클릭하면 기본 프로그램으로 연다.
- `.md` 파일은 툴 안 미리보기로 연다.
- 루트 폴더 경로는 코드에 넣지 않고 로컬 설정 파일에서 읽는다.

### 메모와 문서의 관계

- 일단 분리한다: 메모 탭(빠른 메모, CSV) / 문서 탭(실제 폴더·파일).
- 나중에 합치고 싶으면 메모를 `.md` 파일로 옮겨 문서 탭에서 관리하는 방법이 있다. 그때 메모 탭만 바꾸면 된다.

## 정해야 할 것

- 일정·근태: 무엇을 기록하나 (출퇴근 시각, 연차, 온콜 대응 시간?)
- 알람 방식: 툴을 트레이에 상주시키고 타이머로 체크(추천) / 작업 스케줄러
- 콘솔 창: 바로가기 속성 "실행: 최소화"로 처리(제안)
- 파일 서버: 증적이 무엇인지, 메일 양식·받는 사람, 용량 증설이 무엇을 바꾸는지
