# WorkTool

Windows에서 혼자 쓰는 업무 통합 GUI 툴. PowerShell 7 + WinForms, 외부 모듈 없음.

- 설치·실행·테스트 명령: [COMMANDS.md](COMMANDS.md)
- 요구사항과 진행 순서: [ROADMAP.md](ROADMAP.md)
- 이 문서: 구조와 각 부분이 하는 일

## 파일 하나로 쓰기 (복사 한 번)

`dist/WorkTool.ps1`은 아래 파일들을 하나로 묶은 자동 생성 파일입니다. 기능은 같습니다.

1. GitHub에서 `apps/WorkTool/dist/WorkTool.ps1`을 열고 복사 아이콘(Copy raw file)을 누릅니다.
2. 업무 PC의 WorkTool 폴더에 `WorkTool.ps1`로 저장합니다. 기존 폴더에 두면 `data` 폴더의 기존 데이터를 그대로 씁니다.
3. `pwsh`에서 `.\WorkTool.ps1`로 실행합니다.

- 묶음 파일은 직접 고치지 않습니다. 원본을 고친 뒤 `pwsh build/Build-Bundle.ps1`로 다시 만듭니다.
- 업데이트 전에는 기존 창·트레이를 모두 종료하세요. 같은 `data` 폴더를 쓰는 새 실행본의 중복 실행을 막습니다. 메모 저장이 실패하면 끝내기 전에 「저장하지 않고 끝낼까요?」를 묻습니다. [아니요]를 누르고 파일 잠금이나 폴더 쓰기 권한을 확인한 뒤 다시 저장하세요.
- 모듈 코드는 문자열로 실행하지 않고 그대로 들어가 있습니다(`New-Module` 블록). 데이터 폴더만 "묶음 파일 옆 `data`"로 바뀝니다.

## 구조

```
WorkTool\
  Start-WorkTool.ps1   진입점. 모듈을 불러와 왼쪽 메뉴에 붙이고 메인 창을 띄운다
  modules\
    Storage.psm1       저장 담당
    UiHelper.psm1      화면 공통 (색, 글꼴, 배율, 버튼, 목록, 입력칸, 메시지 창, 앱 아이콘)
    Schedule.psm1      일정·알람 화면
    Attendance.psm1    근태 화면
    Memo.psm1          메모 화면
  data\                실제 데이터 (git 제외)
```

툴은 자기 위치(`$PSScriptRoot`) 기준으로 동작하므로 WorkTool 폴더를 어디에 두든 된다. 네트워크 드라이브보다는 로컬 디스크가 낫다(실행 정책에 걸릴 수 있다).

## 원칙

- PowerShell 7 전용(`#Requires -Version 7`). 5.1 호환은 필요해지면 그때 고친다.
- 외부 반입 없음: `Install-Module`, 외부 DLL 안 쓴다. 기본 cmdlet과 .NET만 쓴다.
- 현장 값(경로, 서버 이름 등)은 코드에 넣지 않는다. 나중에 로컬 설정 파일에서 읽는다.
- 다른 모듈은 파일을 직접 읽고 쓰지 않고 Storage만 거친다.

## Start-WorkTool.ps1

- 메인 창: 왼쪽 메뉴(이름, 날짜, 기능 버튼) / 가운데 화면 / 아래 상태 표시줄.
- 창 크기는 화면 작업 영역 비율(65% × 80%)로 잡는다. 최대화 가능, F11은 테두리 없는 전체 화면.
- 왼쪽 메뉴 맨 위 `≡ WorkTool`을 누르거나 Ctrl+B로 메뉴를 접고 편다. 접으면 아이콘만 남고, 메뉴 이름은 마우스를 올리면 풍선 도움말로 보인다.
- **트레이 상주**: 창의 X는 트레이로 숨긴다(처음 한 번 안내 풍선). 트레이 아이콘 더블클릭 또는 우클릭 → 열기로 다시 띄우고, 우클릭 → 종료로 완전히 끈다. 윈도우 종료·로그오프 때는 그냥 닫힌다(저장하지 못한 메모가 있으면 끝낼지 묻는다).
- 종료하면 트레이 아이콘과 떠 있는 알림 창을 정리한다. 앱 아이콘은 파일 없이 코드로 그린다(`New-UiAppIcon`).
- 기능 추가 방법: `modules\<Module>.psm1`을 만들고 `New-<Module>View` 함수가 화면(Control)을 돌려주게 한 뒤, `$features` 목록에 한 줄 넣는다.
  ```powershell
  @{ Module = 'Memo'; Title = '메모'; Icon = 0xE70B }
  ```
  `Icon`은 윈도우 기본 아이콘 글꼴(Segoe Fluent Icons / Segoe MDL2 Assets)의 글자 코드. 예: 홈 `0xE80F`, 메모 `0xE70B`, 달력 `0xE787`, 폴더 `0xE8B7`, 메일 `0xE715`, 설정 `0xE713`.

## UiHelper.psm1

| 함수 | 하는 일 |
|---|---|
| `Get-UiTheme` | 색 모음 (Back, Card, Sidebar, Accent, Text, SubText, Border 등) |
| `Get-UiFont [크기] [-Bold]` | 테마 글꼴 |
| `Get-UiSize <픽셀>` | 화면 배율에 맞춘 크기 (100% 기준 픽셀을 넣는다) |
| `New-UiPadding <왼> [위] [오] [아래]` | 배율 맞춘 Padding. 하나만 넣으면 사방 같은 값 |
| `New-UiButton <글자> [-Primary]` | 일반 버튼 / 강조 버튼 |
| `New-UiNavButton`, `Set-UiNavSelected` | 왼쪽 메뉴 버튼 (메인 전용) |
| `New-UiFieldLabel <글>` | 입력 칸 왼쪽 이름표 |
| `New-UiDatePicker <형식> [-Time]` | 날짜·시각 입력 |
| `New-UiListView @(@('이름', 폭), ...)` | 표 형태 목록. 마지막 칸이 남는 폭을 채운다 |
| `New-UiAppIcon` | 창·트레이 아이콘 |
| `Show-UiMessage <글> [제목]` | 경고 메시지 창 |
| `Confirm-UiYesNo <글> [제목]` | 예/아니요 창. 예면 `$true` |

- **테마**: 하늘색 파스텔. 색은 파일 맨 위 `$script:theme`에서 바꾼다.
- **글꼴**: 후보 목록(Pretendard, SUIT, Noto Sans KR, 나눔 계열, 맑은 고딕) 중 PC에 설치된 첫 번째를 쓴다. 지금 쓰는 글꼴은 상태 표시줄에 나온다. 순서를 바꾸려면 `$fontCandidates`를 고친다. 글꼴을 새로 설치하는 건 외부 반입이라 하지 않는다.
- **배율**: 메인이 `SetHighDpiMode`를 먼저 부르고 UiHelper를 불러와야 배율이 맞게 읽힌다.

## Storage.psm1

| 함수 | 하는 일 |
|---|---|
| `Get-Records <이름>` | `data\<이름>.csv`를 읽는다. 없으면 아무것도 안 돌려주므로 `@(Get-Records x)`로 감싸서 쓴다 |
| `Save-Records <이름> <기록들>` | 기록 전체를 저장한다 |
| `New-RecordId` | 새 기록용 짧은 ID (12자) |

- **안 깨지는 저장**: 임시 파일(`.tmp`)에 먼저 쓰고 `File.Replace`로 바꿔치기한다. 저장 중에 꺼져도 원래 파일은 남는다. 직전 파일은 `.bak`으로 하나 남는다.
- **Excel 호환**: CSV를 UTF-8 BOM으로 저장해서 Excel로 열어도 한글이 안 깨진다. 단, Excel로 열어둔 상태에서는 파일이 잠겨 저장이 실패한다.
- **값은 전부 문자열**: CSV라서 읽으면 모두 문자열이다. 날짜·숫자는 쓰는 쪽에서 변환한다.
- 읽기·쓰기에 실패하면 항상 예외를 올린다. 읽기 실패를 빈 목록으로 넘기면 다음 저장에서 기존 데이터를 덮어쓰기 때문이다.
- 이름은 영문·숫자·`_`·`-`만 된다.
- 나중에 SQLite 등으로 바꿀 때는 이 파일만 고친다.

## Schedule.psm1

- 화면: 왼쪽 달력·오늘 버튼·다가오는 7일 / 오른쪽 고른 날 일정 목록과 편집 칸.
- 저장 파일: `data\schedule.csv` (Id, Date, Time, Title, Note, Alarm, Repeat, LastAlarm, Updated)
- 시각을 비우면(하루 종일) 알람은 쓰지 않는다. 알람: 없음 / 정시 / 5분·10분·30분·1시간·하루 전. 반복: 없음 / 매일 / 평일 / 매주 (시작일부터).
- 달력에는 반복 없는 일정이 있는 날만 굵게 표시한다 (매일 반복까지 표시하면 전부 굵어진다).
- **알람**: 15초마다 확인한다. 알람 시각부터 일정 시각 30분 뒤까지 툴이 켜져 있으면(트레이 포함) 한 번 울린다. 소리 + 화면 오른쪽 아래 맨 위 알림 창(확인 / 5분 뒤 다시). 여러 개면 위로 쌓인다.
- 울린 알람은 `LastAlarm`에 남겨서 툴을 다시 켜도 같은 알람이 또 울리지 않는다. 반복 일정은 회차마다 따로 울린다.
- 툴이 꺼져 있을 때는 울리지 않는다 (작업 스케줄러를 쓰지 않기로 했다).

## Attendance.psm1

- 화면: 위 달 이동(◀ ▶ 이번 달)과 "지금 출근" / 이번 달 요약 / 왼쪽 62% 목록, 오른쪽 38% 편집.
- 저장 파일: `data\attendance.csv` (Id, Type, StartDate, EndDate, StartTime, EndTime, Place, Detail, Updated)
- 종류별 칸 (`$script:types`에서 바꾼다):

| 종류 | 날짜 | 시각 | 장소 | 마지막 칸 |
|---|---|---|---|---|
| 출근 | 하루 | 시작 | - | 메모 |
| 업무외시간 근무 | 하루 | 시작~끝 | - | 내용 |
| 출장 | 시작일~종료일 | - | O | 목적 |
| 휴가 | 시작일~종료일 | - | - | 종류 (연차, 반차 등 고르거나 직접 입력) |

- **지금 출근**: 오늘 날짜·지금 시각으로 출근 기록을 바로 남긴다. 오늘 기록이 있으면 알려주고 안 남긴다.
- **야간 근무**: 끝 시각이 시작보다 이르면 다음 날로 본다 (22:00~02:30 = 4:30, 목록에 "(다음날)").
- **요약**: 출근 일수 · 업무외 근무 건수와 합계 시간 · 출장 일수 · 휴가 일수. 달을 걸치는 기록은 그 달에 들어가는 날만 센다. 휴가는 주말을 빼고, 종류에 "반차"가 들어가면 0.5일.
- 편집은 "저장"을 눌러야 저장된다 (메모처럼 자동 저장하지 않는다). 날짜는 문자열 `yyyy-MM-dd`, 시각은 `HH:mm`로 저장한다.

## Memo.psm1

- 화면: 왼쪽 32% 검색·목록(최근 수정 순), 오른쪽 68% 버튼 줄·제목·본문.
- 저장 파일: `data\memo.csv` (Id, Title, Body, Created, Updated)
- 자동 저장: 다른 메모를 고르거나, 새 메모를 누르거나, 창을 닫을 때 바뀐 내용이 있으면 저장한다.
- 끝낼 때 저장하지 못하면 「저장하지 않고 끝낼까요?」를 묻는다(기본은 아니요). 트레이로 숨길 때 저장하지 못하면 창을 다시 띄우고 이유를 알린다.
- 단축키: Ctrl+S 저장, Ctrl+A 전체 선택(여러 줄 TextBox는 기본으로 안 돼서 직접 넣었다).
- 제목이 비어 있으면 저장 시각(`yyyy-MM-dd HH:mm:ss`)을 제목으로 쓴다.
- 파일을 못 읽으면 경고를 띄우고 그 실행 동안은 저장·삭제를 막는다(빈 목록으로 덮어쓰기 방지).
- 저장 실패(Excel이 파일을 잡고 있는 경우 등)는 경고 창으로 알리고, 편집 내용은 그대로 둔다.
- 구현 메모: WinForms 이벤트 핸들러는 함수가 끝난 뒤에 실행되므로, 핸들러에서 쓰는 컨트롤과 상태는 모두 `$script:` 변수에 둔다.
