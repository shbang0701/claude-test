# 요구사항과 진행 순서

## 완료

- 뼈대: 메인 창, 탭, 모듈 로딩
- Storage: CSV 저장 (임시 파일 교체, .bak)
- 메모: 검색·목록·편집, 자동 저장, 빈 제목은 저장 시각
- 화면 틀: 왼쪽 메뉴(접기/펼치기), 하늘색 파스텔 테마, 설치된 글꼴 자동 선택, F11 전체 화면
- 근태 1차: 출근 / 업무외시간 근무 / 출장 / 휴가 기록, 월별 목록·요약, 지금 출근
- 일정·알람: 달력, 반복(매일/평일/매주), 알람(정시~하루 전), 알림 창·다시 알림, 트레이 상주

## 진행 순서

1. 서버/랙 현황
2. 파일 서버 작업 기록·증적·메일 본문
3. 문서 탭, 마크다운 미리보기 (아래 요구사항)
4. 홈 화면: 오늘 일정·근태 요약
5. 실사용 실행: 바로가기 (콘솔 창 최소화)

순서는 언제든 바꿀 수 있다. 탭 하나가 폴더 하나라서 서로 영향이 적다.

업무 탭(스크립트를 폼으로 실행하는 틀)은 `docs/plans/workflows-design.md`의 단계대로 만든다. 파일 서버 작업 같은 업무 기능은 그 틀에서 실행하는 `scripts/`의 스크립트로 붙인다.

## 요구사항 (대기)

### 메일 본문 (파일 서버 등)

- Outlook 호환 HTML로 만든다: 표 기반 배치, 인라인 스타일, 글꼴은 맑은 고딕(받는 사람 PC에 없는 글꼴을 쓰지 않는다).
- 클립보드에 HTML과 일반 텍스트를 같이 넣어서 Outlook에 붙여넣으면 서식이 유지되게 한다.

### 마크다운 미리보기

- 메모 본문을 편집 / 미리보기로 전환해서 볼 수 있게 한다.
- WPF 버전에 공통 모듈로 만들었다 (`wpf/core/Markdown.psm1` · `Highlight.psm1` · `Mermaid.psm1`, 설명은 `wpf/README.md` 「마크다운 보기」). 메모 탭은 편집 | 미리보기로 쓴다. 문서 탭은 .md도 원래 프로그램으로 열기로 해서 이 모듈을 쓰지 않는다.
- 구현: PowerShell 7에 들어 있는 Markdig로 읽어 WPF 문서로 그린다. 투명 창이라 `WebBrowser`는 쓸 수 없어서, Mermaid도 직접 배치해서 그린다. 외부 반입 없음.

### 문서 탭 (폴더 트리)

- WPF 버전에 만들었다 (`wpf/addons/docs/Docs.psm1`). 고른 폴더를 왼쪽 트리로, 오른쪽에 파일 목록.
- 파일은 모두 더블클릭하면 기본 프로그램으로 연다. `.md`도 툴 안 미리보기 없이 기본 프로그램으로 연다(사용자 결정, 2026-10-23).
- 폴더 경로 · 즐겨찾기는 코드에 넣지 않고 데이터 폴더의 `settings.json`에서 읽는다.

### 메모와 문서의 관계

- 일단 분리한다: 메모 탭(빠른 메모, CSV) / 문서 탭(실제 폴더·파일).
- 나중에 합치고 싶으면 메모를 `.md` 파일로 옮겨 문서 탭에서 관리하는 방법이 있다. 그때 메모 탭만 바꾸면 된다.

## 정해야 할 것

- 콘솔 창: 바로가기 속성 "실행: 최소화"로 처리(제안)
- 파일 서버: 증적이 무엇인지, 메일 양식·받는 사람, 용량 증설이 무엇을 바꾸는지
