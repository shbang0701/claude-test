# Word 운영 매뉴얼 작성법

## 1. 두 파일의 역할

- `01_운영매뉴얼_템플릿.docx` — 실제로 납품할 문서. 복사해서 쓴다.
- `02_Word_블록라이브러리.docx` — 조각 모음. 여기서 복사해 위 문서에 붙인다.

두 파일은 같은 스타일을 쓰므로, 템플릿 안에 붙여 넣을 때는 그냥 Ctrl+V 해도 서식이 유지된다.

## 2. 스타일

서식은 모두 스타일에 들어 있다. 직접 글자 크기나 색을 바꾸지 말고 스타일을 고른다.
스타일 이름이 전부 `IT-`로 시작하므로 [홈] 탭 스타일 목록 위쪽에 모여 있다.
(스타일 창: Alt+Ctrl+Shift+S)

| 스타일 | 쓰는 곳 |
|---|---|
| 제목 1 / 제목 2 | 장·절 제목. 번호(1., 1.1)는 **자동**이므로 직접 입력하지 않는다 |
| 제목 3 | 절 안의 작은 구분. 번호 없음 |
| IT-단계 | 절차의 각 단계. 번호 자동, 제목이 바뀌면 1부터 다시 시작 |
| IT-단계설명 | 단계에 붙는 보충 설명 |
| IT-단계하위 | a. b. 로 나뉘는 하위 동작 |
| IT-명령 | 그대로 입력하는 명령. 여러 줄은 Shift+Enter |
| IT-출력 | 화면에 나오는 결과. 길면 `…`로 줄인다 |
| IT-주의 / IT-경고 | 실수하기 쉬운 지점 / 되돌리기 어려운 위험 |
| IT-확인 | 성공 판정 기준 |
| IT-참고 | 몰라도 수행에 지장 없는 배경 설명 |
| IT-체크 / IT-글머리 | 순서 없는 확인 항목 / 나열 |
| IT-그림 · 캡션 · IT-화면안내 | 화면 캡처와 그 설명(①②③) |
| IT-표머리 / IT-표본문 / IT-표제목 | 표 안 글자와 표 제목 |
| IT-코드 / IT-치환값 / IT-UI | 문장 안에서 글자만 선택해 적용 |
| IT-작성안내 | 작성용 메모. 완성 후 전부 삭제 |

표는 표 스타일 두 가지를 쓴다.
`IT-표`(머리글 있는 일반 표)와 `IT-정보표`(항목·값 2열).

## 3. 단계를 어떻게 쓸 것인가

### 한 단계 = 한 동작

지시문은 동사로 끝낸다. "확인한다", "입력한다", "재시작한다".
"~할 수 있다", "~하면 된다"는 쓰지 않는다. 읽는 사람이 판단할 여지를 남기지 않는다.

### 밀도는 세 가지 중에서 고른다

| 밀도 | 구성 | 이럴 때 |
|---|---|---|
| 간단 | 지시문 + 명령 | 실패해도 영향이 없고 결과가 뻔한 작업 |
| 표준 | 지시문 + 명령 + 확인 | 결과를 보고 다음으로 넘어가야 하는 작업 |
| 상세 | 작업 정보 + 경고 + 지시문 + 설명 + 치환값 + 명령 + 출력 + 확인 + 분기 | 값을 바꿔 넣거나, 실패하면 서비스에 영향이 있는 작업 |

**모든 단계에 같은 항목을 붙이지 않는다.** 세 번 연속 같은 문장이 나오면 그 항목은 빼도 된다는 뜻이다.

### 빠지면 안 되는 것

수행에 필요한 정보는 절차 어딘가에 **한 번은** 있어야 한다. 매 단계마다 반복할 필요는 없다.

| 정보 | 어디에 |
|---|---|
| 실행 위치(어느 장비·어느 화면) | 절차 맨 앞 작업 정보표에 한 번 |
| 대상과 권한 | 작업 정보표 |
| 사전 조건 | 작업 정보표. 단계별로 다르면 해당 단계 앞에 주의로 |
| 바꿔 넣을 값 | 3개 이하면 명령 안에 `<서비스명>`처럼, 4개 이상이면 치환값 표로 |
| 성공 여부 | 확인이 필요한 단계 뒤에만 IT-확인 |
| 위험 | 해당 동작 **바로 앞**에 IT-경고 |
| 되돌리기 | 절차 끝에 롤백 절차로 |

### 명령·출력·입력값 구분

- 파란 왼쪽 막대가 있는 상자 = **입력하는 명령**
- 막대 없는 회색 상자 = **화면에 나오는 결과**
- 주황색 굵은 글씨 `<이런 값>` = **환경에 맞게 바꿔 넣을 값**

명령 블록 안에서 `<...>`로 감싼 글자는 치환값 서식이 자동으로 적용되어 있다.
새로 입력할 때는 그 부분만 선택하고 `IT-치환값` 글자 스타일을 적용한다.

### 화면 캡처

캡처 안에 글씨를 그려 넣지 말고, 캡처 아래 ①②③(IT-화면안내)로 설명한다.
①②③은 자동 번호가 아니라 고정 기호다(블록을 여러 개 써도 번호가 이어지지 않게 하려는 것이다).
항목을 추가할 때는 앞 줄을 복사해 기호만 다음 것으로 바꾼다.
나중에 화면이 바뀌어도 그림만 갈아 끼우면 된다.
캡처 위에 번호나 강조 표시가 꼭 필요하면 PPT 12쪽의 주석 도형을 복사해 쓴다.

## 4. 예시와 실제 절차 구분

- `〈 〉` 안의 글자는 **채워 넣어야 할 자리**다. 문서를 넘기기 전에 하나도 남아 있으면 안 된다.
- 회색 점선 테두리의 안내 문단(`IT-작성안내`)은 작성자용 메모다. 완성 후 전부 지운다.
  스타일 창에서 `IT-작성안내` → 마우스 오른쪽 → **모든 인스턴스 선택** → Delete 하면 한 번에 지워진다.
- 템플릿 3장에 있는 절차는 **구성 예시**다. 실제 환경에서 확인한 명령과 판정 기준으로 교체한다.

## 5. 자주 하는 실수

- 제목에 "1.", "2."를 직접 입력한다 → 자동 번호와 겹쳐 "1. 1. 개요"가 된다.
- 단계 사이를 Enter로 띄운다 → 간격은 스타일에 들어 있다. 빈 줄을 넣으면 줄 간격이 어긋난다.
- 명령을 여러 줄 넣으려고 Enter를 누른다 → 상자가 여러 개로 나뉜다. Shift+Enter를 쓴다.
- 주의를 절차 끝에 몰아 쓴다 → 읽는 사람은 이미 실행한 뒤다. 해당 동작 바로 앞에 둔다.
- 캡처를 붙여 넣고 크기를 눈대중으로 줄인다 → 그림 자리를 선택하고 **그림 바꾸기**를 쓰면 크기가 유지된다.
