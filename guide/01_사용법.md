# 사용법

문서마다 안에 쓰는 법이 적혀 있다. 이 문서는 그 요약이다.

## 공통 — 복사와 붙여넣기

| 상황 | 붙여넣기 옵션 | 결과 |
|---|---|---|
| 라이브러리 안에서 (템플릿 ↔ 블록) | 그냥 Ctrl+V | 스타일이 같아 그대로 유지된다 |
| 다른 양식의 문서로 | **원본 서식 유지** | 상자 · 색 · 표 모양이 유지되고 필요한 스타일이 따라 들어간다 |
| 글만 필요할 때 | 텍스트만 유지 | 서식 없이 글자만 |

Word에서 매번 고르기 번거로우면
`파일 → 옵션 → 고급 → 잘라내기, 복사 및 붙여넣기 → 다른 프로그램 간 붙여넣기` 를
'원본 서식 유지'로 바꿔 둔다.

PowerPoint에서 **대상 테마 사용**을 고르면 붙여넣은 문서의 색을 따라간다.
이 라이브러리의 모양 그대로 쓰려면 **원본 서식 유지**.

## Word

서식은 모두 스타일에 있다. 글자 크기나 색을 직접 바꾸지 말고 스타일을 고른다.
이름이 전부 `Doc-`으로 시작하므로 스타일 목록(Alt+Ctrl+Shift+S) 위쪽에 모여 있다.

- **제목 1 · 2** — 번호(1., 1.1)는 자동이다. 직접 입력하지 않는다.
- **Doc-단계** — 번호 자동. 중간에 단계를 끼워 넣으면 뒤 번호가 밀린다.
  제목이 바뀌면 1부터 다시 시작한다.
- **Doc-입력 / Doc-결과** — 입력하는 것(파란 막대 상자)과 나타나는 것(회색 상자)을 구분한다.
  여러 줄은 상자 안에서 Shift+Enter.
- **Doc-주의 · 경고 · 확인 · 참고** — 경고와 주의는 해당 동작 **앞**, 확인은 **뒤**에 둔다.
- **Doc-작성안내** — 작성용 메모. 완성 후 스타일 창에서 ‘모든 인스턴스 선택’ → Delete.

절차를 쓸 때 매 단계에 모든 항목을 반복하지 않는다.
실행 위치 · 필요한 것 · 사전 조건은 **절차 앞 정보표에 한 번**,
판정 기준은 **확인이 필요한 단계 뒤에만** 쓴다.

한 줄에 안 들어가는 제목, 빽빽한 줄 간격 같은 문제는 블록 문서 9장(문단과 글자 다루기)에
샘플과 함께 정리해 두었다.

**장 제목을 새 쪽에서 시작하지 않으려면**: 제목 1 스타일 수정 → 서식 → 단락 →
줄 및 페이지 나누기 → ‘단락 앞에서 페이지 나누기’ 해제. 한 번만 하면 문서 전체에 적용된다.

## PowerPoint

19장은 **내용만 바꾸면 되는 장면**, 9장은 **부품 도구상자**다.

- 슬라이드 통째로: 왼쪽 축소판에서 오른쪽 클릭 → 복사
- 도형만: Shift를 누른 채 여러 개 선택 → 복사
- 글자: 도형을 두 번 눌러 바로 수정. 묶인 도형은 Ctrl+Shift+G로 해제
- 차트: 오른쪽 클릭 → 데이터 편집 → 숫자만 바꾸면 그래프가 따라 바뀐다
- 선: 끝점을 도형 가장자리에 대면 연결점(●)에 붙는다. 붙여 두면 도형을 옮겨도 따라온다

깔끔하게 만드는 순서는 26 · 27장에 전후 비교로 넣어 두었다.
요약하면 — 크기를 같게, 줄을 맞추고, 간격을 같게, 색은 네 가지 안에서.

## Excel

도형을 쓰지 않는다. 행 높이 · 열 너비 · 테두리 · 채우기 · 조건부 서식만으로 만든다.

- **셀 시각요소** 시트 — 카드 · 배지 · 구분선 · 진행 막대 · 아이콘 · 셀로 그린 도식.
  각 요소 옆에 만드는 법이 적혀 있다.
- **표 서식** 시트 — 기본 · 줄무늬 · 합계 · 인쇄용 네 가지. 줄무늬는 색을 칠하지 않고
  조건부 서식 수식(`=MOD(ROW(),2)=0`)으로 준다.
- **일정표** 시트 — 시작 · 종료 주차만 넣으면 막대가 칠해진다. 조건부 서식 수식 한 줄이다.
- **실무 함수** 시트 — 왼쪽 자료를 대상으로 실제 계산되는 수식 18개. 수식 칸을 그대로 복사해 쓴다.
- **리본 기능** 시트 — 틀 고정 · 필터 · 드롭다운 · 조건부 서식 · 인쇄 제목이 이미 적용되어 있다.
  눌러 보고 같은 방법으로 내 파일에 적용한다.

범위만 복사할 때는 붙여넣을 곳에서 오른쪽 클릭 → **선택하여 붙여넣기 → 서식**.
행 높이와 열 너비까지 가져가려면 행 · 열 전체를 선택해 복사한다.

## 인쇄와 PDF 전 점검

1. Word: Ctrl+A → F9 (목차 · 그림 번호 갱신)
2. 회색 안내 문단 삭제, `〈` 로 검색해 빈 자리 확인
3. 보기 → 여러 쪽 으로 어색한 쪽 나눔 확인
4. Excel: 보기 → 페이지 나누기 미리 보기 로 잘리는 위치 확인
5. PDF 저장은 파일 → 다른 이름으로 저장 → PDF
