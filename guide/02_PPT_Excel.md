### 쓰는 법

- **슬라이드 통째로**: 왼쪽 축소판에서 오른쪽 클릭 → 복사 → 대상 파일에 붙여넣기.
  대상 파일의 디자인을 따르려면 붙여넣기 옵션에서 **대상 테마 사용**, 이 파일 모양 그대로 쓰려면 **원본 서식 유지**.
- **도형만**: Shift를 누른 채 여러 도형을 고르고 복사한다.
- **글자**: 도형을 두 번 누르면 바로 고칠 수 있다. 도형 크기는 글자에 맞춰 자동으로 늘어나지 않으므로,
  글자가 길면 도형을 키우거나 줄바꿈한다.
- **정렬**: 여러 도형을 선택 → [도형 서식] → 맞춤 → '가로 간격을 동일하게'.
- **선**: 선 끝을 노드 가장자리에 대면 연결점(●)에 붙는다. 붙여 두면 노드를 옮겨도 선이 따라온다.
- **묶인 도형**: Ctrl+Shift+G로 그룹을 해제한 뒤 개별 편집한다.

### 구성도를 그릴 때

1. 영역(존) 박스를 먼저 그리고 **맨 뒤로 보내기**.
2. 노드를 올리고 이름·역할만 적는다. IP·포트·구간 이름은 선 옆 라벨(둥근 태그)로 뺀다.
3. 한 줄에 노드가 5개를 넘으면 줄을 나눈다.
4. 색은 세 가지 안에서 쓴다. 파랑 계열(주 경로), 회색(대기·부가), 빨강(장애·주의).

### Word에 넣을 때

PPT에서 복사 → Word에서 **붙여넣기 옵션 → 원본 서식 유지**.
도형 상태로 들어오므로 Word 안에서도 글자를 고칠 수 있다.
그림으로 고정하고 싶으면 '그림'으로 붙여 넣되, 이후에는 수정할 수 없다.

## Excel — `04_운영문서_표모음.xlsx`

| 시트 | 쓰는 때 | 특징 |
|---|---|---|
| 안내 | 시트 목록과 공통 규칙 | 아래쪽 빈 표를 복사해 새 표를 만들 수 있다 |
| 작업계획·결과 | 작업 전 계획 → 작업 후 결과 | 결과 칸은 목록 선택, 고르면 색이 바뀐다 |
| 점검 체크리스트 | 일·주·월 정기 점검 | 판정 건수가 위쪽 요약에 자동 집계된다 |
| 장비·IP 관리대장 | 장비·주소 목록 | 자동 필터와 틀 고정이 걸려 있다 |
| 장애 기록 | 장애 발생~복구 시간순 기록 | '사실/추정'을 구분해 적는다 |
| 방안 비교 | 선택지 비교 | 가중치와 점수를 넣으면 합계가 자동 계산된다 |
| 인수인계 목록 | 인계 항목과 진행 상태 | 완료율이 자동 계산된다 |

### 쓰는 법

- 행을 추가할 때는 **기존 행을 복사해 삽입**한다. 서식과 선택 목록이 함께 따라온다.
  맨 아래 빈 행에서 시작하면 목록 상자가 없을 수 있다.
- 판정·상태 칸은 직접 입력하지 말고 목록에서 고른다. 글자가 다르면 자동 집계에서 빠진다.
- 한 건(작업·장애)마다 시트를 복사해 쓴다. 시트 탭 오른쪽 클릭 → 이동/복사 → 복사본 만들기.
- 인쇄는 가로 방향, 폭 1쪽 맞춤으로 설정되어 있다. 표 머리글은 쪽마다 반복된다.
- 수식은 Office 2016에서 동작하는 함수만 썼다(COUNTIF, COUNTA, COUNTBLANK, SUMPRODUCT, TEXT).
