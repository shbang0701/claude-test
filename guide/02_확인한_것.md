# 확인한 것과 확인하지 못한 것

이 환경에서는 Microsoft Office를 실행할 수 없어 **LibreOffice로 열어 PDF로 변환하고 그 결과를
눈으로 확인**했다. 아래는 그 구분이다.

## 확인한 것

**파일**
- 네 파일 모두 정상적으로 열리고 PDF로 변환된다
  (문서 템플릿 12쪽 · Word 블록 18쪽 · 슬라이드 28장 · Excel 8쪽).

**Word**
- 제목 번호(1, 1.1)와 단계 번호가 자동으로 매겨진다.
- **단계를 중간에 끼워 넣으면 뒤 단계 번호가 자동으로 밀린다.**
- 제목이 바뀌면 단계 번호가 1부터 다시 시작한다.
- 설명을 세 줄짜리 긴 문장으로 바꿔도 들여쓰기 · 줄 간격 · 뒤쪽 배치가 유지된다.
- 이미지를 교체해도 틀 크기와 아래 내용의 위치가 유지된다(비율이 다르면 늘어남).
- 여백과 기본 글꼴이 다른 문서에 ‘원본 서식 유지’로 붙여 넣으면 상자 · 표 모양이 유지되고,
  표 너비는 그 문서 여백에 맞춰 자동으로 줄어든다.
- 스타일이 따라오지 않으면(텍스트만 유지) 상자와 표 테두리가 사라진다.
- 줄 간격 1.15 / 1.4 / 1.6, 자간 −0.3pt / +0.5pt, 장평 90%가 화면에 다르게 나타난다.

**PowerPoint**
- 도형 · 연결선 · 꺾인 연결선 · 곡선 · 말풍선 · 괄호 · 화살촉 5종이 모두 표시된다.
- 테마 그림자와 그라데이션을 제거해 평평하게 나온다.
- 막대 · 선 · 100% 누적 막대 차트가 PowerPoint 기본 차트로 들어간다(값 편집 가능한 형태).
- 반투명 채우기(사진 위 글상자)가 적용된다.

**Excel**
- 수식이 실제로 계산된다: SUM · COUNTIF · COUNTIFS · SUMIF · SUMIFS · AVERAGEIF · VLOOKUP
  · INDEX+MATCH · IFERROR · IF · TEXT · EOMONTH · ROUND · RANK · REPT · 날짜 계산 · 문자 연결.
- 조건부 서식이 동작한다: 데이터 막대 · 아이콘 집합 · 색조 · 셀 강조 · 수식 기반(줄무늬, 간트 막대).
- 드롭다운 목록이 이름 정의(`상태목록`)를 참조해 동작한다.
- 틀 고정 · 자동 필터 · 인쇄 제목 · 페이지 폭 맞춤이 적용되어 있다.

## 확인하지 못한 것 — Office 2016에서 처음 쓸 때 점검할 것

- **글꼴 모양** — 이 환경에 맑은 고딕 · Consolas가 없어 대체 글꼴로 확인했다.
  실제 Word에서는 줄바꿈 위치와 쪽수가 조금 달라질 수 있다. 쪽 나눔은 처음 한 번 확인한다.
- **표 칸 ‘텍스트 맞춤’(한 줄에 다 넣기)** — 파일에는 설정해 두었으나 LibreOffice는 이 기능을
  화면에 반영하지 않는다. Word에서 글자가 칸 너비에 맞춰 줄어드는지 확인한다.
  (Word 블록 문서 9.3 방법 1)
- **문서 열 때 목차 자동 갱신** — 자동 갱신 설정을 넣어 두었으나 Word에서의 동작은 확인하지 못했다.
  갱신되지 않으면 Ctrl+A → F9.
- **□ · ① · ○ · △ · × 기호** — 한글 글꼴에 있는 문자지만 실제 Word 화면에서의 모양은 확인하지 못했다.
- **조건부 서식 아이콘 집합의 아이콘 모양** — Excel과 LibreOffice의 아이콘이 다르다.
  Excel에서 원하는 아이콘으로 바꾸려면 규칙 관리 → 규칙 편집.
- **스파크라인은 넣지 않았다** — 파일 생성 도구가 지원하지 않는다.
  필요하면 Excel에서 삽입 → 스파크라인(2016 지원)으로 직접 넣는다.
- **Office UI 조작** — 붙여넣기 옵션 단추, 그림 바꾸기, 도형 연결점 붙임, 차트 데이터 편집,
  기본 도형으로 설정 등은 파일 구조상 문제가 없음을 확인했을 뿐 실제 클릭으로 확인하지는 못했다.
- **PowerPoint 도형을 Word에 붙여넣기** — 구조상 가능하지만 실제 붙여넣기 결과는 확인하지 못했다.
