# 수정 · 복사 · 인쇄

## 1. 다른 문서에 붙여 넣을 때

붙여 넣은 뒤 나타나는 **붙여넣기 옵션** 단추에서 무엇을 고르느냐가 전부다.

| 상황 | 고를 것 | 결과 |
|---|---|---|
| 이 라이브러리 안(템플릿 ↔ 블록) | 그냥 Ctrl+V | 같은 스타일이라 그대로 유지된다 |
| 다른 회사 양식 문서 | **원본 서식 유지** | 상자·색·표 모양이 유지되고, 필요한 스타일이 그 문서에 추가된다 |
| 본문 글만 필요할 때 | 텍스트만 유지 | 서식 없이 글자만 들어간다 |

**확인한 것**: 여백과 기본 글꼴이 다른 문서에 '원본 서식 유지'로 붙여 넣으면
명령·출력 상자, 주의·확인 상자, 표가 그대로 유지되고 표 너비는 그 문서 여백에 맞춰 자동으로 줄어든다.
본문 글꼴은 붙여 넣은 문서의 기본 글꼴을 따라간다(그 문서와 어울리게 하려는 의도다).
맑은 고딕으로 통일하려면 붙여 넣은 범위를 선택하고 글꼴을 바꾼다.

**주의**: 스타일이 따라오지 않으면(텍스트만 유지 등) 상자와 표 테두리가 모두 사라진다.
블록을 옮길 때는 반드시 '원본 서식 유지'를 쓴다.

Word에서 매번 고르기 번거로우면
`파일 → 옵션 → 고급 → 잘라내기, 복사 및 붙여넣기 → 다른 프로그램 간 붙여넣기`를
'원본 서식 유지'로 바꿔 둔다.

## 2. 서식을 고칠 때

- **문서 전체를 한 번에**: 스타일 이름 오른쪽 클릭 → 수정. 예를 들어 `IT-명령`의 배경색을 바꾸면
  문서 안 모든 명령 상자가 같이 바뀐다.
- **이 한 곳만**: 해당 문단만 선택해 직접 서식을 준다. 스타일은 건드리지 않는다.
- 직접 준 서식을 되돌리려면 해당 문단 선택 후 Ctrl+Space(글자) / Ctrl+Q(문단).
- 스타일이 엉켰을 때는 서식 지우기 후 스타일을 다시 적용한다.

## 3. 번호가 이상할 때

- 제목 번호가 "1. 1. 개요"처럼 겹친다 → 제목에 번호를 직접 입력한 것이다. 입력한 번호를 지운다.
- 단계 번호가 앞 절차에서 이어진다 → 첫 단계에서 오른쪽 클릭 → **1에서 다시 번호 매기기**.
  (제목 1·2·3 아래에 절차를 두면 자동으로 1부터 시작한다)
- 번호 서식이 깨졌다 → 해당 문단에 `IT-단계` 스타일을 다시 적용한다.

## 4. 이미지 교체

그림 자리를 선택 → 오른쪽 클릭 → **그림 바꾸기 → 파일에서**.

**확인한 것**: 원래 그림의 크기와 위치가 그대로 유지되고, 아래쪽 캡션·설명·본문은 움직이지 않는다.
다만 새 그림의 가로세로 비율이 다르면 **늘어나 보인다**.
이때는 그림 선택 → [그림 서식] → 크기 창에서 '가로 세로 비율 고정'을 켜고 높이를 조정하거나,
자르기 → 채우기를 쓴다. 캡처는 16:9에 가깝게 잘라 넣는 것이 가장 깔끔하다.

## 5. 표 다루기

- 행 추가: 마지막 칸에서 Tab.
- 줄무늬: 표 안 클릭 → [표 도구] 디자인 → '줄무늬 행' 체크.
- 열 너비: 경계선을 끌거나, 표 전체 선택 → 레이아웃 → 자동 맞춤 → 창에 자동으로 맞춤.
- 표가 쪽을 넘어갈 때 머리글을 반복하려면: 머리글 행 선택 → 레이아웃 → 머리글 행 반복.
- 한 행이 두 쪽으로 잘리지 않게 하려면: 표 속성 → 행 → '행이 페이지를 넘길 때 줄 바꿈' 해제.

## 6. 인쇄 · PDF 전 점검

1. **목차·그림 번호 갱신** — Ctrl+A → F9 → '모두 업데이트'.
   (문서를 열 때 자동 갱신되도록 설정해 두었지만, 인쇄 직전에 한 번 더 하는 편이 안전하다)
2. **안내 문단 삭제** — 스타일 창에서 `IT-작성안내` → 모든 인스턴스 선택 → Delete.
3. **남은 `〈 〉` 찾기** — Ctrl+F로 `〈`를 검색해 하나도 남지 않았는지 확인한다.
4. **쪽 나눔 확인** — 보기 → 여러 쪽. 제목만 페이지 끝에 남았거나 표가 어색하게 잘렸는지 본다.
   해당 문단 선택 → 단락 → 줄 및 페이지 나누기 → '다음과 함께'를 켠다.
5. **PDF 저장** — 파일 → 다른 이름으로 저장 → PDF. '문서 속성' 체크는 해제하는 편이 낫다.
6. **인쇄 결과** — 표와 그림이 오른쪽 여백을 넘지 않는지, 9pt 미만으로 줄인 글자가 없는지 본다.

Excel은 이미 A4 가로·폭 1쪽 맞춤·머리글 반복으로 설정되어 있다.
인쇄 전에 [보기] → 페이지 나누기 미리 보기로 잘리는 위치만 확인한다.

## 7. 확인한 것과 확인하지 못한 것

이 환경에서는 Microsoft Office를 실행할 수 없어 **LibreOffice 24.2로 열어 PDF로 변환하고
그 결과를 눈으로 확인**했다. 아래는 그 구분이다.

### 확인한 것

- 네 파일 모두 정상적으로 열리고 PDF로 변환된다(Word 13쪽·13쪽, PPT 15쪽, Excel 7쪽).
- 제목 번호(1, 1.1)와 단계 번호가 자동으로 매겨진다.
- **단계를 중간에 끼워 넣으면 뒤 단계 번호가 자동으로 밀린다.**
- 제목이 바뀌면 단계 번호가 1부터 다시 시작한다.
- 단계 설명을 세 줄짜리 긴 문장으로 바꿔도 들여쓰기·줄 간격·뒤쪽 배치가 유지된다.
- 이미지를 교체해도 틀 크기와 아래 내용의 위치가 유지된다(비율이 다르면 늘어남).
- 여백·글꼴이 다른 문서에 '원본 서식 유지'로 붙여 넣으면 블록 모양이 유지된다.
- 스타일이 따라오지 않으면 상자·표 모양이 사라진다(그래서 '원본 서식 유지'가 필요하다).
- Excel의 선택 목록, 조건부 서식 색, 자동 집계 수식이 동작한다.

### 확인하지 못한 것 (Office 2016에서 첫 사용 시 점검 권장)

- **글꼴 모양** — 이 환경에는 맑은 고딕·Consolas가 없어 대체 글꼴로 확인했다.
  실제 Word에서는 줄바꿈 위치와 쪽수가 조금 달라질 수 있다. 쪽 나눔은 처음 한 번 확인한다.
- **문서 열 때 목차 자동 갱신** — 자동 갱신 설정을 넣어 두었으나 Word에서의 동작은 확인하지 못했다.
  갱신되지 않으면 Ctrl+A → F9.
- **□ 기호와 ①②③** — 체크 목록의 □(U+25A1)와 화면 안내의 ①②③은 한글 글꼴에 있는 문자지만,
  실제 Word 화면에서의 모양은 확인하지 못했다. ①②③은 자동 번호가 아니라 직접 입력한 기호다.
- **붙여넣기 옵션 단추의 실제 동작**, **그림 바꾸기 메뉴**, **표 도구 디자인의 줄무늬 행** 등
  Office UI 조작은 문서 구조상 문제가 없음을 확인했을 뿐 실제 클릭으로 확인하지는 못했다.
- **PowerPoint의 연결점 붙임과 그룹 해제**, **Excel 데이터 유효성 창의 표시**도 같다.
