# 아이콘 60종

PowerPoint 안에서 쓸 때는 `03_슬라이드_요소.pptx` 30~31쪽의 도형을 복사한다.
색과 크기를 바꿀 수 있어 그쪽이 편하다.

이 폴더의 파일은 **Word · Excel · 다른 도구에 넣을 때** 쓴다.

| 폴더 | 무엇 | 언제 |
|---|---|---|
| `png_남색` | 진한 남색 PNG 60개 | 흰 배경 문서 |
| `png_흰색` | 흰색 PNG 60개 | 어두운 배경 · 표지 |
| `svg` | 벡터 SVG 60개 | 크게 키워도 안 깨져야 할 때 |
| `아이콘_목록.png` | 전체 목록 한 장 | 찾을 때 |

Word에 넣기: 삽입 → 그림 → 이 디바이스에서. 배치는 '텍스트 줄 안'으로 둔다.
Excel에 넣기: 삽입 → 그림. 셀에 맞추려면 그림 서식에서 크기를 직접 입력한다.
SVG는 Office 2016에서 열리지 않을 수 있다. 그때는 PNG를 쓴다.
