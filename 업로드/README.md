# IT 인프라 문서 템플릿 · 에셋 세트

Excel 장비 전·후면도와 랙 파일, PowerPoint 구성 요소를 복사해 쓰는 세트입니다.
**Excel·PowerPoint 2016의 복사/붙여넣기, 글자 수정, 셀 스타일 선택만으로 사용합니다.** 매크로·VBA·외부 서비스·추가 프로그램은 필요 없습니다.

Excel 탭 색: 회색 = 안내 / 주황 = 부품 / 파랑 = 빈 양식(`양식-`) / 초록 = 작성 예시(`예시-`).

## 바로 시작

1. 가장 비슷한 `예시-` 또는 `양식-` 탭 우클릭 → **이동/복사 → 대상 랙 파일 → 복사본 만들기**.
2. 시트 이름을 `U20 SRV-01`처럼 바꾸고, 1~2행의 장비명·모델·위치·시리얼·관리 IP를 입력합니다.
3. [부품]에서 필요한 **범위 전체**를 복사해 같은 크기의 자리에 붙입니다. 열 너비와 행 높이는 바꾸지 않습니다.
4. 연결된 포트 칸에 도면 번호를 입력하고, **홈 → 셀 스타일**에서 `포트 서비스` 등의 용도 색을 선택합니다.
5. 아래 연결 표의 같은 번호 행에 포트명·상대 장비·케이블 라벨을 적습니다. 번호가 분홍색이면 누락·중복 여부를 확인합니다.
6. [랙] 목록에 U·높이·면·장비명·시스템·모델·구분·시트 이름을 적습니다. 기존 수식으로 실장도와 링크가 표시됩니다.

새로운 검사 절차나 별도 입력 도구는 추가하지 않았습니다. 원래 있던 목록 선택·분홍 경고·랙 자동 표시는 유지했습니다.

## 섀시의 컴퓨트 노드

베이 안에는 **베이 번호 / 굵은 호스트명 / 작은 모델**을 적습니다. 연결 표 위의 **장착 목록**에는 `베이 / 호스트명 / 모델 / 시리얼 / 관리 IP / 용도·OS / 비고`를 적습니다. 도면과 장착 목록의 호스트명·모델은 직접 같은 내용으로 작성합니다.

전높이(2베이) 블레이드는 [부품] **G07, C225:I252 (7×28칸)**을 복사합니다. 점유하는 두 베이 번호를 함께 적고, 장착 목록에서는 한 행에 정리합니다. 점유 방향·베이 조합은 장비별 현장 확인 사항입니다.

`예시-ENC-01`과 랙 예시의 `U01 ENC-01`은 베이 1~6에 **ESX-01~ESX-06**을 넣었습니다. 호스트명은 작성 예시이며 실제 자산명이 아닙니다. 모델은 원본의 `BL460c Gen10` 표기를 유지했습니다. 시리얼·관리 IP·용도·OS는 확인되지 않아 **현장 확인**으로 적었습니다. 나머지 베이는 빈 상태입니다.

### Synergy 12000 양식

`양식-Synergy12000`은 **10U** 신규 양식입니다. 아래 수량은 요청 기준을 반영한 것이며, 제조사 배치 도면을 검증했다는 뜻은 아닙니다.

| 면 | 반영한 구성 |
|---|---|
| 전면 | 반높이 컴퓨트 12베이 + 어플라이언스 2베이 |
| 후면 | ICM 1~6 + 프레임 링크 모듈 2 + 팬 1~10 + 전원 6 |

위치·번호 방향·실제 포트명·전높이 점유 조합은 **현장 확인**으로 표시했습니다. 팬·전원은 빈 양식의 시작값이므로 모두 `빈`으로 두었습니다. 실제 장착 상태에 맞게 스타일을 선택하고, 필요한 포트는 [부품]에서 복사합니다.

## 팬·전원 / 디스크 / 글씨

| 대상 | 조작 |
|---|---|
| 팬·전원 장착 | **상태 칸**만 선택 → `팬·전원 장착`: 회색 ◎ |
| 팬·전원 블랭크 | 같은 상태 칸 → `팬·전원 빈칸`: 점선 + 빈 |
| 디스크 장착·빈칸 | 기존 디스크 칸 → `디스크 장착` / `디스크 빈칸` → 용량 또는 빈 입력 |
| RAID | 디스크 묶음에 굵은 바깥쪽 테두리 → 아래 줄에 `RAID5 · DATA` → `RAID 표시` |

팬·전원 상태 칸은 **글자를 지우지 말고 스타일만 바꿉니다.** 모듈 제목이나 포트 번호 칸이 아니라 ◎/빈 표시 칸을 선택합니다. 기존 도면 외곽선은 유지됩니다. c7000 예시는 블레이드 1~6 기준으로 **팬 8개 장착, 팬 3·8은 빈 상태**입니다.

**Alt+Enter로 줄 나누지 말 것.** 디스크는 줄바꿈 없이 셀에 맞춤으로 표시합니다. SFF 세로 베이는 90°, LFF는 가로입니다. 이미 만들어진 디스크 칸끼리 복사하고 스타일을 바꿔 기존 방향을 유지합니다.

병합된 포트명·표·랙 목록·베이 이름은 셀에 맞춤으로 자동 축소됩니다. 옆 칸으로 흘러야 하는 **한 칸짜리 모듈 제목·메모는 제외**했습니다. 아주 긴 글씨는 지나치게 작아질 수 있으므로 모델 상세 정보는 장착 목록에 적습니다.

## 번호 세 가지와 앞·뒤 기준

| 구분 | 적는 곳 |
|---|---|
| 도면 번호 | 색 칸의 흰 숫자. 장비 안에서 유일 |
| 포트명 | 도면의 포트 아래 회색 글씨, 연결 표의 포트명 칸 |
| 케이블 라벨 | 연결 표의 노란 칸에만. 양쪽 장비 표에서 같은 라벨 |

베이 번호는 회색 베이 표기이며 도면 번호와 다릅니다. 반복되는 슬롯 포트는 기존 규칙인 슬롯×100+포트를 사용합니다. **전면은 랙 앞문 쪽에서 본 면**입니다.

여러 박스로 된 시스템은 박스마다 시트를 만들고 [랙]의 시스템 칸에 같은 이름을 적습니다. 선반 위 장비는 기존대로 면 `선반`을 사용합니다.

## 격자·인쇄 기준

Excel 도면은 **도형 없이 셀 격자**입니다. 열 너비 **2.0**, 기본 행 높이 **12pt**를 유지했습니다. 원본에 있던 제목·표·랙의 예외 행 높이는 전체 재배치를 피하기 위해 그대로 보존했습니다. 새 장착 목록·부품·Synergy 본문은 12pt입니다.

19인치 장비의 도면 폭은 기존 61칸(C~BK), 부품의 기본 크기도 그대로입니다. 포트·디스크·RAID의 테두리 보존 설정을 유지했습니다. Excel·PPT 글꼴은 **맑은 고딕**으로 통일했습니다.

인쇄는 **A4 가로·고정 100%**입니다. 원본의 너비 맞춤을 해제했고, 여백·바닥글을 보존했습니다. 반복 제목은 일반 시트 **1~3행**, 랙은 **1~5행**입니다. 큰 섀시는 전면·후면·장착 목록·연결 표를 나누어 인쇄합니다. 사용 전 **Ctrl+P에서 쪽 경계**를 확인합니다. 실제 Excel 글꼴 폭·프린터에 따른 가로 페이지 분할은 별도 확인이 필요합니다.

## PPT 사용

요소 한 번 클릭(그룹 선택) → 복사 → 대상 PPT에 붙여넣기 → 그룹 안 글자를 다시 클릭해 수정합니다. 아이콘은 PPT 5~7쪽의 도형을 복사합니다. 색은 RGB, 글꼴은 맑은 고딕으로 지정했습니다.

2쪽 목차의 잘림을 수정했습니다. 10·21쪽 R02에는 Excel에 있는 `STG-01-DAE1`, `AIX-01`, `AIX-01-IO1`을 반영했고, 21쪽 R02 여유는 **9U**로 맞췄습니다. 22쪽 SRV-01 연결 번호·라벨은 원본대로 유지했습니다.

## 수정 후 확인 범위

저장된 파일을 다시 열어 **기존 수식 688개와 미리 저장된 계산 값**, 기존 조건부 서식·목록·링크·테두리 보존 설정을 확인했습니다. 병합 겹침은 없고, 예시의 도면 번호·케이블 라벨은 유지했습니다. 세부 결과는 `변경목록_및_확인사항.md`에 있습니다.

**Excel·PowerPoint 2016 자체를 실행한 검수는 하지 못했습니다.** 특히 SFF의 90°+셀에 맞춤, 병합 칸의 축소, 상태 스타일 클릭, 100% 인쇄 쪽 경계는 실제 Office에서 확인해야 합니다. PDF는 맑은 고딕이 설치되지 않은 제작 환경에서 대체 한글 글꼴을 포함해 생성했습니다.

Synergy 및 기존 대형 섀시·GPU 서버·IBM Power/I/O 드로어의 실제 배치는 실물·공식 배치도와 재대조하지 않았습니다. 원본의 현장 확인 표시는 남겨 두었습니다. 외부 케이블 7개는 상대 장비 표가 없어 양쪽 일치를 확인하지 못했습니다.
