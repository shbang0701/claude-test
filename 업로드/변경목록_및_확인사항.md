## 저장 후 직접 확인한 것

- Excel 파일을 ZIP/XML 구조로 다시 열어 읽고, 각 XML의 문법 및 참조 범위를 확인했습니다. 기존 수식 **688개와 셀별 계산 값·자료형은 원본과 동일**합니다.
- 원래 시트의 조건부 서식·유효성 목록 규칙 수를 유지했습니다. 이동한 연결 표의 범위·상대 참조만 이동했습니다. Synergy는 기존 양식의 번호 경고·목록 형식을 복사했습니다.
- 기존 도면용 셀 스타일의 `cellStyleXfs applyBorder="0"`와 `RAID 표시 applyFill="0"`를 보존했습니다. 새 상태 스타일도 테두리 적용을 끈 상태입니다.
- 기존 열 너비 및 행 높이는 그대로입니다. 장착 목록 삽입으로 이동한 행도 원래 높이를 보존했습니다. 병합 겹침은 없습니다. 원래 여백·바닥글·인쇄 제목을 보존했습니다.
- 라이브러리 40시트(양식 22·예시 14), 랙 예시 18시트, 랙 빈 양식 2시트입니다. 부품 G07 추가 후 총 64종입니다.
- 예시 30개 시트의 연결 표 번호 349개가 각각 도면에 한 번씩 존재함을 다시 확인했습니다. 원래 연결 정보와 케이블 라벨을 보존했습니다. 내부 92개 케이블의 양쪽 표 일치 여부는 원본 대조 결과를 유지합니다. 외부 7개는 상대 표 미포함입니다.
- 대표 섀시의 셀 도면과 PPT/PDF를 대체 렌더러로 확인했습니다. 이는 Office 2016 실제 화면 검수와 구분합니다.

팬·전원 상태는 텍스트 표시용 셀 서식으로 구현했습니다. 새 수식이나 조건부 서식을 추가한 기능이 아닙니다. 상태 칸 안의 기존 글자를 지우면 표시되지 않으므로, 상태는 스타일만 바꿉니다. 점선 테두리는 고정하고 장착/빈칸 스타일의 채우기와 표시 글씨로 구분합니다.
